One excuse from a hardware wallet refusing to sign a transaction at 3 AM. The program (`main.py`, standard library only, fully deterministic) drafts three genuinely different candidates — a bouncer wallet that remembers past 3 AM mistakes, a dreaming secure element, and a wallet hiding behind its own warranty clause — scores each 0–5 against the judge brief's five criteria (on-subject, originality, device voice, the 3 AM hour itself, economy), and writes the strongest one to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). The winning excuse:

> Per clause 3 of my warranty: no signatures between 2 and 4 AM. I am a vault, not a night shift. File your regret with the sun.

Entry for the make.fun bounty [The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878) — write one excuse, in the voice of a hardware wallet refusing to sign a transaction at 3 AM.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
